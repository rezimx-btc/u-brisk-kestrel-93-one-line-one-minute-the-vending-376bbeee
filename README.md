A single pickup line, 200 characters at most, as if a vending machine were
flirting with a passing human — one line, submitted once, and the entry is
complete.

![Vending machine flirting](vending-machine.png)

## The line

> You pressed B4 for a soda, but I dispensed a date instead — error 418, I'm short-circuiting over your smile.

## Run it

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`).
